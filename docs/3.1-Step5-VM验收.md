# 3.1 第 5 步 VM 验收（界面三态 + CLI 签名 IPC）

> **验收结果（2026-10-23，VM）：全部通过。**

> 这一步补上用户能看见的部分：
> - 界面明确显示“不是所有者 / 密钥不可用 / 未初始化”，规则只读；
> - CLI 的 `--block / --list-blocked / --unblock-all` 改为签名 IPC，不再直接写 WFP；
> - `--migrate / --recover` 仍是管理员恢复命令，保留直接 WFP。

## 一次性复制（管理员 PowerShell）

```powershell
& {
    $ErrorActionPreference = 'Stop'
    cd C:\Users\VM\Downloads\默认项目\dist-tools

    $version = (Get-Item .\WinAppGuardSetup.exe).VersionInfo.ProductVersion
    Write-Host "版本 = $version"
    if ($version -notlike '3.1+*') { throw "版本不是 3.1+：$version" }

    .\WinAppGuardSetup.exe --repair
    if ($LASTEXITCODE -ne 0) { throw "Setup --repair 失败，退出码 $LASTEXITCODE" }
    Write-Host "[PASS] Setup --repair" -ForegroundColor Green

    .\WinAppGuard.SelfCheck.exe --protected-mode-ui-test --no-pause
    if ($LASTEXITCODE -ne 0) { throw "protected-mode-ui-test 失败，退出码 $LASTEXITCODE" }
    Write-Host "[PASS] protected-mode-ui-test" -ForegroundColor Green

    .\WinAppGuard.SelfCheck.exe --service-auth-test --no-pause
    if ($LASTEXITCODE -ne 0) { throw "service-auth-test 失败，退出码 $LASTEXITCODE" }
    Write-Host "[PASS] service-auth-test" -ForegroundColor Green

    .\WinAppGuard.SelfCheck.exe --service-acl-test --no-pause
    if ($LASTEXITCODE -ne 0) { throw "service-acl-test 失败，退出码 $LASTEXITCODE" }
    Write-Host "[PASS] service-acl-test" -ForegroundColor Green

    .\WinAppGuard.SelfCheck.exe --cli-test --no-pause
    if ($LASTEXITCODE -ne 0) { throw "cli-test 失败，退出码 $LASTEXITCODE" }
    Write-Host "[PASS] cli-test" -ForegroundColor Green

    .\WinAppGuard.SelfCheck.exe --ui-check --no-pause
    if ($LASTEXITCODE -ne 0) { throw "ui-check 失败，退出码 $LASTEXITCODE" }
    Write-Host "[PASS] ui-check" -ForegroundColor Green

    Write-Host "自动化验收通过。" -ForegroundColor Green
}
```

## 1. CLI 走签名 IPC（所有者）

用所有者身份、管理员 PowerShell：

```powershell
cd C:\Users\VM\Downloads\默认项目\dist-tools

# 先看当前列表
.\WinAppGuard.exe --list-blocked

# 阻止一个测试程序（不存在时请换成本机真实 exe）
.\WinAppGuard.exe --block "C:\Windows\System32\notepad.exe"

# 确认列表里有它
.\WinAppGuard.exe --list-blocked
```

期望：

- 命令输出正常，规则确实出现在列表；
- 服务日志出现 `IPC 写操作：PID …，SID …，路径 …，命令 write.rules...`；
- 不再由 CLI 直接写 WFP。

然后清理：

```powershell
# 只预览，不删
.\WinAppGuard.exe --unblock-all
# 确认后删
.\WinAppGuard.exe --unblock-all --yes
.\WinAppGuard.exe --list-blocked
```

期望：第一次退出码 1；`--yes` 后删除成功，列表为空。

## 3. 界面三态

### 3.1 所有者（正常）

普通权限打开界面：

- 状态栏正常；
- 规则可编辑（写操作弹一次 UAC）。

### 3.2 非所有者（B）

用 B 登录，打开界面：

- 状态栏显示“受保护模式：当前账户不是所有者（离线模式，界面只读）”；
- 规则页只读；
- 点击状态栏不会尝试启动服务。

### 3.3 密钥不可用（可选）

在所有者会话里：

1. 关闭界面；
2. 停服务；
3. 把 `C:\ProgramData\WinAppGuard\protected-mode\client-key.dpapi` 改名；
4. 启动界面。

期望：状态栏显示“密钥不可用（离线模式，界面只读）”，提示用 `--rotate-key`。

恢复：

```powershell
# 以所有者身份
.\WinAppGuardSetup.exe --rotate-key
```

### 3.4 未初始化（3.0 升级场景）

如果机器上还没有 `protected-mode` 密钥，界面应显示“受保护模式未初始化”，
提示运行 Setup `--install/--repair`，而不是让用户反复点“启动服务”。
