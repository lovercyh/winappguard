# 4.2 VM 验收说明

> 4.2 = ARP 欺骗检测 + 虚假 DHCP 检测 + 防护页三子标签 + 事件落盘。
> 只在验收 VM 上跑；开发机只编译/打包。

## 1. 自动验收

管理员 PowerShell，在 `dist-tools` 里运行：

```powershell
chcp 65001 > $null
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
cd C:\Users\VM\Downloads\默认项目\dist-tools

& .\4.2-验收脚本.ps1 -LogPath "$env:USERPROFILE\Desktop\wag-4.2-验收.txt"
"退出码 = $LASTEXITCODE"
```

新增的自动项：

- `--lan-test`：ARP/DHCP 规则、冷却、信任、保留期、状态文件；（离线）
- `--service-lan-test`：局域网采集是否在跑、设置、DHCP 阻断过滤器创建/解除、清空。

## 2. ARP 欺骗（第二台 Linux VM）

```bash
# 在攻击 VM 上（把 IP 换成验收机的地址）
sudo arpspoof -i eth0 -t <验收机IP> <网关IP>
```

期望：

1. 5 秒内「防护 → 局域网」出现 **高危“网关 MAC 变化”**，详情含旧/新 MAC；
2. 点「信任此网关」后不再重复告警；
3. 停止攻击、重启服务后，基线仍然生效（不会重新学习成攻击者的 MAC）。

## 3. 虚假 DHCP（第二台 VM）

用 dnsmasq 或 yersinia 在验收机所在网段起一个 DHCP：

1. 出现 **“未知 DHCP 服务器”** 高危；
2. 同时起两个 → **“多个 DHCP 服务器”**；
3. 修改 OFFER 的网关/DNS → **“DHCP 下发参数变化”**；
4. 租期设为 30 秒 → **“DHCP 租期异常短”**。

## 4. DHCP 临时阻断（可选，POC 通过才测）

1. 打开「允许临时阻断 DHCP 服务器（默认关闭）」；
2. 选中 rogue 服务器 → 「临时阻断此服务器（10 分钟）」；
3. 客户端续租时不应再拿到 rogue 的 OFFER；
4. 10 分钟后自动解除，或手动「解除阻断」；
5. 若 POC 证明广播包拦不住，页面上的按钮应不可用，并在 `docs/4.2-POC结果.md` 记录。

## 5. 网卡范围

「纳入检测的网卡」应：

- 包含：物理以太网、Wi-Fi、VPN（TAP / WireGuard / OpenVPN 等）；
- 不包含：Hyper-V vEthernet、VMware VMnet、VirtualBox Host-Only、WSL、Docker、Loopback。

## 6. 基线、落盘与保留期

1. 首次启动静默学习 10 分钟（或直到网关 + DHCP 都出现），期间不告警；
2. 重启服务后事件仍在页面里；
3. 保留期改为 15 / 30 天，旧文件按新期限清理；
4. 「清空…」删除事件并解除阻断，不动基线；
5. 「重置基线…」清空网关/DHCP 基线并重新静默学习。

## 7. 界面与回归

- 防护页三个子标签（端口扫描 / 局域网 / IDS）可切换；
- 托盘 IDS 气泡能定位到 IDS 子标签；
- 局域网页「每 3 秒自动刷新」默认开，取消后表格不再变化；
- 中英文、100%/150% DPI 不截断；
- 3.4–4.1 回归：规则、白名单、IDS、锁网、记录、DNS、流量、防护页。

## 8. 24 小时误报观察

正常办公/浏览一整天：

- ARP 事件应为 0（换路由器除外）；
- DHCP 事件应为 0（合法第二台 DHCP 需手动信任）；
- 观察服务 CPU / 内存 / 丢包（只记录，不设门禁）。

## 9. 失败时收集

- `wag-4.2-验收.txt`；
- `C:\ProgramData\WinAppGuard\logs` 最近 1200 行；
- `C:\ProgramData\WinAppGuard\lan\state.json`；
- `C:\ProgramData\WinAppGuard\lan\events-*.jsonl`（前 50 行）；
- 局域网页截图（事件 + 网关 + DHCP 服务器）；
- 攻击 VM 的命令与时间点。
