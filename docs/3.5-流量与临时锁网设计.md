# 3.5 流量统计、DNS 与临时锁网设计

> 状态：设计中（2026-10-25）。
> 范围：每程序上行/下行字节、DNS 查询记录、服务代查进程路径、临时锁网（定时严格模式）。
> **不做**：包内容 / URL / DPI / HTTPS 解密、内核驱动、签名、定时规则（按星期/时间段）、常驻严格模式。

## 1. 目标与非目标

### 1.1 目标

1. 让用户看到**每个程序本次运行收发了多少数据**；
2. 让用户看到**最近哪些程序查询了哪些域名**；
3. 解决「界面读不到提权/受保护进程路径」的问题，由服务代查；
4. 提供「临时锁网 30 分钟 / 2 小时」，到点自动恢复。

### 1.2 非目标

- 不抓包、不存载荷、不解析 URL 路径；
- 不做 HTTPS 中间人；
- 不做按流量特征实时阻断（IPS 留给 4.0）；
- 不做按星期/时间段的规则（留给 3.6 或更后）；
- 不把严格模式做成常驻。

## 2. 数据来源（POC 决策）

### 2.1 每程序流量

两条候选路线，必须先 POC：

| 路线 | 数据 | 覆盖 | 复杂度 |
|---|---|---|---|
| A. TCP 扩展统计 | `GetPerTcpConnectionEStats` 的 `DataBytesIn/Out` | 仅 TCP；短连接可能漏 | 低 |
| B. ETW 网络事件 | `Microsoft-Windows-Kernel-Network` / `TCPIP` | TCP + UDP | 中高 |

POC 通过标准：

- A：与任务管理器 / `netstat -e` 量级一致；单连接字节数合理；CPU 可忽略；
- B：10 分钟事件量、CPU、内存可接受（空闲 <1%，下载时 <5%），无持续丢事件。

决策：

- A 够用 → 先做 TCP 版本，界面明确标注「仅 TCP，短连接可能漏计」；
- B 可接受 → 做完整版本；
- 都不可接受 → 只做连接数/频率，不宣称流量精度。

> 绝不能把近似值写成精确值；界面和文档都要写清边界。

### 2.2 DNS

- 优先用 ETW `Microsoft-Windows-DNS-Client`：域名、PID、时间、结果；
- 失败/不支持时退回现有 `DnsCacheReader`（只能“推测”，文案要写清）；
- DoH/DoT 不经过 DNS Client，拿不到时显示「未知」，不假装。

## 3. 数据模型

### 3.1 流量

```text
TrafficKey = 程序完整路径（拿不到路径时用 pid:<pid>:<启动时间>）
TrafficCounters = BytesIn / BytesOut / LastSeenUtc
```

- 服务内存里维护「本次运行」计数；
- 可选按天落盘 `%ProgramData%\WinAppGuard\traffic\YYYYMMDD.json`，保留 7 天，可清空；
- 同程序多 PID 合并到路径；路径为空时按 PID 兜底，并标注「未知程序」；
- 不保存任何载荷。

### 3.2 DNS

```text
DnsRecord = TimeUtc / Pid / ProcessPath / QueryName / Status
```

- 内存环形缓冲（例如 2000 条）+ 可选日文件；
- 保留 7 天，可清空；
- 只记录域名，不记录 URL、不记录响应内容。

### 3.3 进程路径

- `Pid → Path?`；
- 服务以 SYSTEM 调用 `ProcessResolver.TryGetImagePath`；
- 进程已退出 / PPL 保护 → 返回 null，界面显示原因。

## 4. 协议（v2 内新增命令）

协议版本仍是 2；只新增命令，不改已有字段。

| 命令 | 类型 | 说明 |
|---|---|---|
| `query.traffic` | 读 | 返回每程序本次运行上下行 |
| `query.dns` | 读 | 返回最近 DNS 记录（可按 PID/域名过滤） |
| `query.process.paths` | 读 | 批量 PID → 路径 |
| `write.strict.lockdown` | 写 | 临时锁网，带到期时间 |

- 读命令只要求签名，不要求提权；
- 写命令仍要求提权；
- 旧版客户端不会调用新命令，不受影响；
- 新 UI + 旧服务：命令返回「不支持」，界面降级隐藏相关列。

### 4.1 DTO 草案

```text
TrafficDto { Path, Name, BytesIn, BytesOut, LastSeenUtc, IsPathKnown }
DnsDto { TimeUtc, Pid, ProcessPath, QueryName, Status }
ProcessPathDto { Pid, Path, Error }
LockdownRequest { DurationSeconds }
LockdownStatus { Active, ExpiresAtUtc, RemainingSeconds }
```

## 5. 服务端

### 5.1 流量采集

- 采集放服务：SYSTEM 权限、常驻、界面关掉仍累计；
- 定时器（例如 2 秒）刷新连接表 → 更新计数；
- 只统计本机进程；回环、短连接按路线能力如实处理；
- 提供 `traffic.reset`（可选）清空本次运行计数。

### 5.2 DNS 采集

- 由服务起 ETW 实时会话；
- 解析失败不影响其他功能；记录 `WAG-DNS-*` 事件码；
- 会话异常退出后自动重试，避免一次失败永久停采。

### 5.3 临时锁网

- 复用严格模式动态会话；
- `write.strict.lockdown` 参数：30 分钟 / 2 小时；
- 服务保存到期时间并启动定时器；
- 到期自动 `StrictModeManager.Disable()`；
- 服务重启/崩溃：动态会话消失，网络自动恢复，不残留锁网；
- 严格模式已经开启时拒绝锁网，返回明确错误。

### 5.4 进程路径代查

- `query.process.paths` 批量最多 64 个 PID；
- 只返回当前仍存在的进程路径；
- 失败返回 `Error`，不抛异常。

## 6. 界面

### 6.1 连接页

- 新增列：上传、下载、总计；
- 按程序聚合，排序兼容；
- 路径为空时自动调用 `query.process.paths` 补全；
- 补不到显示「需要管理员权限 / 进程已退出 / 受保护进程」；
- 流量列悬停提示写明「近似值，短连接/UDP 可能漏计」。

### 6.2 DNS 视图

- 新增「DNS」页签：时间、程序、域名、结果；
- 支持搜索、清空、保留期；
- 不显示 URL 路径；
- DoH 场景显示「未知」。

### 6.3 临时锁网入口

- 严格模式面板：30 分钟 / 2 小时按钮；
- 托盘菜单：同上；
- 锁网期间状态栏/面板显示倒计时；
- 到期气泡「已恢复联网」；
- 确认框说明「未加白名单的程序会断网，到点自动恢复」。

## 7. 隐私与安全

- 只存计数和域名，不存载荷；
- 域名可能敏感：本地保存、可清空、默认保留 7 天；
- 不做任何上传；
- 服务日志固定英文 + 事件码；
- 读命令仅签名；写命令仍要求提权；
- 不改变 3.1/3.4 的权限模型与 WFP DACL。

## 8. 测试

### 8.1 离线

- 流量聚合：同程序多 PID、PID 复用、路径缺失、清零；
- DNS 去重/保留期/损坏文件；
- 锁网到期计算、服务重启不残留；
- `process.paths` 编解码；
- UI 列/页签在 100% / 150% DPI 不截断。

### 8.2 VM

- POC 数字：TCP/ETW 的 CPU、事件量、精度；
- 下载大文件，流量与任务管理器/`netstat -e` 量级一致；
- 提权程序路径能被服务补全并成功阻止；
- DNS 页能记录真实查询；DoH 显示未知；
- 锁网：未白名单程序断网、到点恢复、强杀服务恢复；
- 3.1–3.4 回归。

## 9. 交付物与顺序

1. 本设计文档；
2. POC 工具与 VM 结果（决定流量路线）；
3. 协议 + 服务端采集；
4. UI（流量列、DNS 页、锁网入口）；
5. 进程路径代查；
6. 测试、VM 验收；
7. 文档、版本 3.5、打包。

## 10. 风险

| 风险 | 处理 |
|---|---|
| ETW 事件量过大 | 退回 TCP 统计，界面标注限制 |
| 流量数字与用户预期不符 | 显示「本次运行」而非“总流量”，写明近似 |
| DoH 看不到域名 | 显示未知，不假装 |
| 锁网误操作 | 仅 30m/2h、动态会话、到期/崩溃自动恢复 |
| 读路径泄露 | 仅签名客户端、仅当前存在的 PID |
| UI 3 秒刷新 + 流量聚合卡顿 | 聚合在服务端，UI 只拉快照 |
