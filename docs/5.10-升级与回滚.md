# 5.10 升级与回滚

## 升级顺序

1. 停止运行中的界面进程。
2. 停止 `WinAppGuardSvc`。
3. 替换 `WinAppGuard.exe`、`WinAppGuardSvc.exe`、卸载器。
4. 启动服务。
5. 运行协议自检（`--doctor`）：
   - 服务版本；
   - 协议版本；
   - 关键字段；
   - 模块状态。
6. 任一步失败：保留旧二进制，报告失败原因，不进入半升级状态。

## 版本不匹配

| 场景 | 表现 | 处理 |
|---|---|---|
| v3 UI + v3 服务 | 正常 | — |
| v3 UI + v2 服务 | v3 管道不存在 | 界面提示：服务版本较旧，请运行 `WinAppGuardSetup.exe --repair` |
| v2 UI + v3 服务 | v2 管道不存在 | 旧界面已有“服务未运行”提示，补充修复指引 |
| 协议号不匹配但管道存在 | `VersionMismatch` | 不降级、不猜测，明确提示 |

## 回滚

- 保留 `v5.9.2` tag 和安装包。
- v3 只改“怎么说”，不改数据格式。
- 回滚只需回退二进制：
  1. 停服务；
  2. 安装 5.9.2；
  3. 启动服务。
- 旧状态文件、告警、规则快照、FirstSeen 记录保持可读。
