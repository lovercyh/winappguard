# 5.16：稳定性与安全加固

> 版本：5.16.0  
> 协议：v4

## 1. 修复内容

### P1

- `AuditService` 的每日清理 `if` 被并进注释，导致每 3 秒全量清理；已恢复每天一次。
- 三个 Npcap 采集器 Stop 时先 `pcap_breakloop` 再 Join；线程未退出不 Close，避免 UAF。
- `JsonStateFile.Save` 按路径加锁 + 唯一临时文件，避免并发写坏状态。
- 提权临时文件使用唯一目录 + `CreateNew` + 重解析点检查。

### P2

- 启动时规则/白名单读取延后到窗口显示后。
- 事件文件整文件清理改用本地日期 cutoff，和文件名一致。
- `LanHost` / `AntiScanHost` 定时器增加重入护栏。
- 后台 IPC 排队单独 30 秒，不误报离线。
- Setup 轮询等待服务；关闭界面优先 `CloseMainWindow`，按安装路径匹配。
- ECDsa 公钥验证器缓存。
- 严格模式无事务时拒绝“先删后加”，保留旧会话。

### P3

- GridTable 对全部行做哈希。
- CTS 在窗口关闭后释放。
- IDS 通知定时器纳入 components。
- `RuleExpiry` 时钟回拨不再误判重启。
- CLI 转发 120 秒超时。
- 1.x 遗留严格模式恢复放到 STA 线程。
- 日志行带时区偏移。

## 2. 未修复

交互账户检测失败时仍跳过跨账户检查，保持 5.15 行为。

## 3. VM 验收

1. 审计目录不会每 3 秒被扫描/删除；
2. 反扫描 / 局域网 / 流量页面反复启停不崩溃；
3. 多页面并发刷新不误报离线；
4. 慢启动机器安装/修复不再误报 exit 4；
5. 严格模式刷新失败时旧会话仍生效；
6. 跨午夜事件文件不提前/延后一天删除；
7. 时钟回拨后临时规则不提前解除；
8. CLI 在服务卡死时 120 秒返回。
