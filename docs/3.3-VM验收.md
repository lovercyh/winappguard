# 3.3 VM 验收（安装器双语 / CLI 语言 / 服务日志）

> 用途：在**虚拟机**里验收 3.3；开发机只编译、打包，不跑改系统状态的测试。
> 需要管理员 PowerShell。

## 0. 准备

把发布产物复制到 VM，例如 `C:\Users\VM\Downloads\默认项目\dist-tools`，
其中至少有：

- `WinAppGuardSetup.exe`
- `WinAppGuardUninstall.exe`
- `WinAppGuard.exe`（界面）
- `WinAppGuardSvc.exe`（服务 + CLI 入口）
- `WinAppGuard.SelfCheck.exe`（自检工具）

开发机打包命令：

```powershell
powershell -ExecutionPolicy Bypass -File .\build\publish.ps1
```

## 2. 安装器 / 卸载器双语（固定，不跟随 GUI）

```powershell
.\WinAppGuardSetup.exe --help | Tee-Object -Variable help
if (-not ($help -match 'WinAppGuard 安装工具') -or -not ($help -match 'WinAppGuard Setup')) { throw '帮助不是双语' }
if (-not ($help -match 'Double-click WinAppGuardSetup.exe')) { throw '帮助缺少英文段落' }
```

说明：`--help` 只打印帮助，不改系统。

修复/安装时检查进度行：

```powershell
.\WinAppGuardSetup.exe --repair | Tee-Object -Variable repair
if ($LASTEXITCODE -ne 0) { throw "repair 失败：$LASTEXITCODE" }
$repair -match '服务已启动'      # 中文半句必须存在
$repair -match 'Service started' # 英文半句必须存在
```

卸载器（**手工交互**，直接双击或在该终端里运行，不要用管道输入）：

```powershell
.\WinAppGuardUninstall.exe
# 看到双语文案后输入 n 回车
```

预期：同时看到「WinAppGuard 卸载程序 | WinAppGuard Uninstaller」「将删除：」「This will delete:」，
最后提示 `确定要完全卸载吗？[y/N]  Completely uninstall? [y/N]`；输入 n 后输出“已取消 / Cancelled”。

> 管道输入会让程序判定为非交互模式（`Console.IsInputRedirected = true`），
> 此时它按设计只打印 `--uninstall` 的用法，不会弹确认。

## 3. CLI 语言

### 3.1 `--lang` 单次覆盖

```powershell
$svc = '.\WinAppGuardSvc.exe'
& $svc --cli --help --lang en | Tee-Object -Variable en
& $svc --cli --help --lang zh | Tee-Object -Variable zh

if (-not ($en -match 'Windows program network control')) { throw '英文帮助缺失' }
if ($en -match '[\u4e00-\u9fff]') { throw '英文帮助里混入了中文' }
if (-not ($zh -match '命令行模式')) { throw '中文帮助缺失' }
```

非法参数：

```powershell
& $svc --cli --help --lang fr
# 预期退出码 1，中英双语错误提示
if ($LASTEXITCODE -ne 1) { throw "非法 --lang 退出码应为 1，实际 $LASTEXITCODE" }
```

### 3.2 跟随 GUI 已生效语言

1. 打开 GUI → 状态栏把语言切到 English → **不要重启**。
2. 此时运行：

```powershell
& $svc --cli --help | Select-String 'Windows program network control'
# 预期：仍然是旧语言（中文），因为 GUI 还没重启、AppliedLanguage 还是旧值
```

3. 关闭并重新打开 GUI（确认界面已是英文）。
4. 再运行：

```powershell
& $svc --cli --help | Select-String 'Windows program network control'
# 预期：英文
```

5. 切回中文并重启 GUI，重复一次，确认 CLI 也跟着回到中文。

### 3.3 数据行契约

```powershell
& $svc --cli --list-blocked --lang en | Tee-Object -Variable listEn
& $svc --cli --list-blocked --lang zh | Tee-Object -Variable listZh
```

预期：

- 两种语言下每个规则行都是 3 段、`\t` 分隔；
- 前两段（规则名、路径）完全一致；
- 英文表头是 `# rule name\tprogram path\texpiry`，中文表头不变；
- `--lang en` 输出中除程序路径/用户数据外不应出现中文字符。

## 4. 服务日志（固定英文 + 事件码）

```powershell
$logDir = Join-Path $env:ProgramData 'WinAppGuard\logs'
Get-ChildItem $logDir -Filter '*.log' |
    Sort-Object LastWriteTime -Descending |
    Select-Object -First 1 |
    Get-Content -Encoding UTF8 |
    Select-String 'WAG-' |
    Select-Object -Last 20
```

预期：

- 级别是 `[INFO]` / `[WARN]` / `[OP]` / `[ERROR]`，不是中文；
- 每行都有 `[WAG-...]` 事件码；
- 至少能看到 `[WAG-SVC-002] Service started.` 与 `[WAG-IPC-002] Named pipe created ...`。

异常格式（若日志里有异常）：

```
exception=System.ComponentModel.Win32Exception hresult=0x80004005 nativeErrorCode=5
   at ...
```

不出现 `Message` 的中文句子。

自动断言（服务已在运行时）：

```powershell
$svc = '.\WinAppGuardSvc.exe'
& $svc --cli --lang en --list-blocked | Out-Null   # 触发一次 IPC 读操作
$latest = Get-ChildItem $logDir -Filter '*.log' | Sort-Object LastWriteTime -Descending | Select-Object -First 1
$text = Get-Content $latest.FullName -Raw -Encoding UTF8
if ($text -notmatch '\[WAG-') { throw '日志没有事件码' }
if ($text -match '\[信息\]|\[警告\]|\[错误\]|\[操作\]') { throw '日志仍有中文级别名' }
if ($text -match 'exception=.*\r?\n.*[\u4e00-\u9fff]') { throw '异常行混入中文' }
```

> 注意：用户名、程序路径等**数据**可能本身含中文，这不算日志语言问题。

### 4.1 GUI 日志跟随界面语言

1. GUI 状态栏切到 English，重启界面。
2. 添加一条黑名单规则。
3. 打开 `%LOCALAPPDATA%\WinAppGuard\logs\` 下最新的日志：

```powershell
$log = Get-ChildItem (Join-Path $env:LOCALAPPDATA 'WinAppGuard\logs') -Filter '*.log' |
    Sort-Object LastWriteTime -Descending | Select-Object -First 1
Get-Content $log.FullName -Encoding UTF8 -Tail 5
```

预期：新出现的操作为英文，例如 `[OP] Add to blocklist: C:\Tools\a.exe (scope any).`；
不应再出现 `加入黑名单`。

4. 切回中文并重启，再添加一条规则：新日志行应为中文 `[操作] 加入黑名单：...`。

## 5. 自动化自检

```powershell
foreach ($mode in @(
    '--cli-language-test',
    '--log-format-test',
    '--ui-language-test',
    '--ui-language-dpi-test',
    '--cli-test',
    '--ui-check'
)) {
    .\WinAppGuard.SelfCheck.exe $mode --no-pause
    if ($LASTEXITCODE -ne 0) { throw "$mode 失败：$LASTEXITCODE" }
}
```

预期：全部 `失败 = 0`。

## 7. 完整卸载（验收最后一步）

```powershell
.\WinAppGuardUninstall.exe --uninstall
if ($LASTEXITCODE -ne 0) { throw "卸载失败：$LASTEXITCODE" }
```

预期：

- 输出双语；
- 服务、规则、快捷方式、`%ProgramData%\WinAppGuard`、`%LOCALAPPDATA%\WinAppGuard` 全部删除；
- `sc query WinAppGuardSvc` 返回服务不存在。
