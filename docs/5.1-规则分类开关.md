# 5.1 规则分类开关

## 分类

| id | 显示名 | 规则文件 | 默认 |
|---|---|---|---|
| malware | 恶意软件 | `standard/malware.rules` | 开 |
| exploit | 漏洞利用 | `standard/exploit.rules` | 开 |
| dns | DNS | `standard/dns.rules` | 开 |
| ja3 | TLS / JA3 | `standard/ja3.rules` | 开 |
| coinminer | 挖矿 | `standard/coinminer.rules` | 开 |
| phishing | 钓鱼 | `standard/phishing.rules` | 关 |
| web_client | Web 客户端 | `standard/web_client.rules` | 开 |
| other | 其他 | `standard/other.rules` | 开 |

分类文件按当前标准档筛选条件生成：`Critical/Major + Client_Endpoint + Windows/未标注平台`。
默认分类合计 12,528 条；phishing 单独 1,532 条，默认关闭。

## 运行方式

- 设置页勾选分类并保存；
- 服务把选中的分类文件拼成：

```text
%ProgramData%\WinAppGuard\network-detection\suricata\rules\active.rules
```

- 先执行 `suricata -T` 校验；
- 校验通过后重启 Suricata 子进程；
- 校验失败保留旧 `active.rules` 并显示错误。

全量档直接使用 `all.rules`，忽略分类开关。

## 验收

1. 设置页显示 8 个分类，phishing 默认不勾选。
2. 保存后规则数变为所选分类合计。
3. 取消 malware 后，`nslookup ningzhidata.com` 不再产生 GoldenSpy 告警。
4. 重新勾选 malware 后告警恢复。
5. 全量档不受分类开关影响。
6. 构建 0 警告 0 错误。

## 边界

- 只做分类开关，不做逐条规则开关。
- TLS / JA3 只对应 `emerging-ja3.rules`；其他 TLS SNI 规则仍可能在 malware/exploit 分类中。
- 仍然只告警，不自动拦截。
