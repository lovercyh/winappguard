# 3.7 VM 验收说明

> 3.7 = 用户态 Flow IDS，**只检测、不阻断**。
> 只在验收用的 VMware 虚拟机里跑；开发机只编译 / 打包，不执行会改系统状态的测试。

## 1. 准备

1. 在开发机打包（会生成 `dist` 与 `dist-tools`）：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\build\publish.ps1
   ```

2. 把整个 `默认项目` 文件夹复制到 VM，例如：

   ```text
   C:\Users\VM\Downloads\默认项目\
   ```

   `build/publish.ps1` 会自动把 `3.7-验收脚本.ps1` 同步到 `dist-tools`。

3. 在 VM 里以管理员身份安装 / 覆盖安装：

   ```powershell
   C:\Users\VM\Downloads\默认项目\dist\WinAppGuardSetup.exe --install
   ```

4. 确认版本号是 **3.7**（安装目录里的 `WinAppGuard.exe` / `WinAppGuardSvc.exe`）。

## 2. 自动验收

管理员 PowerShell：

```powershell
cd C:\Users\VM\Downloads\默认项目\dist-tools
powershell -ExecutionPolicy Bypass -File .\3.7-验收脚本.ps1
```

脚本会：

1. 检查界面 / 服务版本与验收包一致；
2. 重启服务；
3. 跑 `--ids-test`（离线规则 / 告警存储 / 状态文件 / 协议 DTO）；
4. 回归 `--traffic-records-test`；
5. 跑 `--etw-network-test`；
6. 回归 `--service-35-test`（流量 + DNS）；
7. 跑 `--service-ids-test`（设置开关 / 抑制增删 / 确认不存在告警 / 清空）；
8. 跑临时锁网（会短暂断网）；
9. 清空流量计数（放在最后）；
10. 检查两个 ETW 会话存在；
11. 检查服务日志里的 `WAG-IDS-001`、`WAG-TRAFFIC-001`、`WAG-DNS-002`，
    以及没有持续的 `WAG-IDS-003` / `WAG-IDS-005` / `WAG-TRAFFIC-003`。

> `--service-ids-test` 会清空 IDS 告警；`--service-traffic-clear-test` 会清空流量计数。
> 两者都**不会**修改规则、白名单或锁网状态。脚本结束时会恢复测试前的 IDS 设置。

## 3. 手工检查

在 VM 里打开界面，切到「IDS」页：

1. 状态行应显示「IDS 已开启 · 标准敏感度 · 采集中 · 只检测、不阻断 · flow … · 事件 … · 未确认 …」。
2. 点「设置…」：
   - 能开关 IDS、切换标准 / 保守、修改保留期、分别开关四条规则；
   - 保存时弹一次 UAC；
   - 已存在的抑制会列出来，可以「取消选中抑制」，同样只弹一次 UAC。
3. 产生一条可控告警（可选）：在 VM 里对同一内网主机快速连多个端口，
   或运行 POC 的合成扫描场景；确认 IDS 页出现「端口 / 主机扫描」告警。
   **不要**对生产网络扫描。
4. 选中告警：
   - 「确认」后状态变「已确认」，未确认计数减一；
   - 「抑制…」选 1 小时 / 24 小时 / 永久，保存后同一规则 / 程序 / 目标不再重复提示；
   - 鼠标停在行上能看到完整路径和证据。
5. 「清空…」：确认框 + UAC，清空后列表为空，`%ProgramData%\WinAppGuard\ids\alerts.jsonl` 被删除。
6. 英文界面：IDS 页签、列头、搜索占位、筛选项、按钮、设置 / 抑制对话框无中文。
7. 100% / 150% DPI：IDS 页顶部按钮不重叠、不越界。
8. 回归：连接页流量列、DNS 页、流量页、30 分钟锁网、3.4 双账户 DACL。

## 4. 观察指标

正常使用 15–30 分钟（浏览网页、看视频、下载），记录：

- IDS 页的 flow 数、事件数、未确认告警数；
- 服务进程 CPU / 内存（任务管理器或 `--service-35-test` 输出）；
- 是否出现误报；如果有，记下规则、程序、目标、证据。

POC 基线（VM，16 核，10 分钟正常使用）：

| 指标 | 数值 |
|---|---|
| 告警 | 0 |
| CPU 平均 / 峰值 | 0.0% / 0.1% |
| 内存峰值 | 56 MB |
| flow 峰值 | 535 |
| 网络事件 | 11,724 |

如果 3.7 的 flow 数或 CPU 明显高于这个基线，先检查：
- 是否有程序在短时间内大量建连（扫描类工具、下载器）；
- `C:\ProgramData\WinAppGuard\logs` 里是否有 `WAG-IDS-*` 错误；
- 服务是否被反复重启。

## 5. 数据位置与清理

| 内容 | 位置 |
|---|---|
| IDS 设置 / 抑制 / 确认状态 | `%ProgramData%\WinAppGuard\ids\state.json` |
| IDS 告警 | `%ProgramData%\WinAppGuard\ids\alerts.jsonl` |
| 服务日志 | `%ProgramData%\WinAppGuard\logs\winappguard-*.log` |

- 告警默认保留 30 天；服务启动时按保留期重写文件。
- 界面「清空…」会删除告警文件和内存记录；不会碰规则。
- 完全卸载仍走 `WinAppGuardUninstall.exe`；IDS 数据目录随安装目录策略处理。

## 6. 失败时收集什么

- `3.7-验收脚本.ps1` 的完整输出（尤其是失败项和退出码）；
- 服务日志最近 600 行；
- `logman query -ets` 输出；
- IDS 页截图（含状态行和告警列表）；
- `state.json` 与 `alerts.jsonl`（如果存在；里面只有元数据，没有载荷）。
