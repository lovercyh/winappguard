# 5.8 新程序联网提醒

> 状态：已实现，待验收
> 日期：2026-11-10
> 范围：独立「新程序联网提醒」页面；IDS / 反网络攻击页「全部已读」。
> 明确不做：自动拦截、自动更新、域名拦截、HTTPS 解密、内核驱动。

## 1. 新程序联网提醒

### 默认状态

- 独立标签页：**新程序联网提醒**。
- 模式默认关闭。
- 关闭时不记录、不更新、不弹气泡；历史记录仍可查看。

### 开启后的记录

- 记录程序路径、进程名、首次联网时间、最近联网时间。
- 模式开启时已在线的程序记为「启用时已在线」基线，不算新程序，不提醒。
- 同一程序多个 PID 按路径合并成一条。
- 路径为空的连接忽略。
- 路径回填后再检查一次。

### 页面

列表列：

- 进程名
- 完整路径
- 首次联网时间
- 最近联网时间
- 状态（新 / 已知）
- 来源（首次发现 / 模式开启时已在线）

操作：

- 搜索程序 / 路径
- 只看新程序
- 刷新
- 阻止联网
- 释放临时阻止
- 加入 / 移出严格模式白名单
- 标记为已知
- 全部已读
- 删除记录
- 清空记录
- 导出（默认 CSV）

模式开启后每 3 秒扫描一次连接，用于检测新程序；连接页关闭自动刷新不会影响这里的检测。模式关闭时定时扫描停止。

### 托盘提醒

- 多个新程序合并成一条气泡。
- 两条气泡至少间隔 **10 秒**。
- 同一程序 **24 小时**内不重复提醒。
- 模式关闭时不弹。

### 存储

```text
%LOCALAPPDATA%\WinAppGuard\first-seen-programs.json
```

只保存：

- 路径
- 进程名
- 首次 / 最近联网时间
- 是否已知
- 是否基线
- 上次提醒时间

不保存 IP、域名、端口、命令行；只在本机，不上传。

### 新程序默认阻止（可选，高风险）

默认关闭。开启后：
- 服务会为新程序创建**临时 WFP 阻止过滤器**，不弹 UAC，不写永久规则；
- 屏幕中央弹出确认框，不使用托盘气泡：
  - 「允许联网」→ 立即释放临时阻止；
  - 「保持阻止」→ 继续阻止；
  - 关闭窗口 / Esc → 按保持阻止处理。
- 临时阻止持续到用户选择；关闭默认阻止、关闭主模式或退出界面时释放；
- 服务停止/重启时动态会话自动清空；
- 页面「处理状态」显示已允许 / 已临时阻止 / 已阻止 / 已解除；
- 默认阻止开启时，删除仍在联网或仍被临时阻止的记录会立即重新弹窗并重新阻止；
- 受保护进程不阻止；
- 只检测 TCP；第一条连接可能已经建立，不能保证挡住第一个包；
- 只使用 UDP 的程序可能不会触发弹窗；
- 这是本项目唯一允许界面免 UAC 创建 WFP 过滤器的路径，命令为
  `guard.new-program.block` / `guard.new-program.release`。

## 2. 全部已读

### 防护 IDS

- 新增「全部已读」按钮。
- 只把当前未读告警标为已读，不清空历史。
- 服务命令：`alert.ids.ack-all`，免管理员权限（只改告警元数据）。

### 反网络攻击

- 新增「全部已读」按钮。
- 服务命令：`alert.network.ack-all`。
- 同样只标记未读告警。

### 新程序联网提醒

- 「全部已读」把列表里所有“新”记录改为“已知”。
- 不删除首次联网时间。

## 3. 诊断包

新增：

```text
data/new-programs.csv

```

`summary.txt` 增加 `firstSeenPrograms` 数量。

## 4. 验证

```text
dotnet build WinAppGuard.sln -c Debug    0 警告 0 错误
SelfCheck --first-seen-test              通过
SelfCheck --ui-check                     通过
SelfCheck --ui-language-test             通过
SelfCheck --export-test                  通过
SelfCheck --diagnostics-test             通过
SelfCheck --cli-test                     通过
SelfCheck --network-detect-test          通过
SelfCheck --ipv6-security-test           通过
```

手工重点：

1. 默认关闭；关闭时启动新程序不记录、不提醒。
2. 开启后当前程序记为基线，不弹气泡。
3. 新程序出现后列表新增，状态为新，10 秒冷却气泡。
4. 同一程序多 PID 只一行。
5. 标记已知、全部已读、删除、清空正常。
6. 阻止 / 加入白名单 / 移出白名单正常。
7. IDS / 反网络攻击「全部已读」正常。
8. 导出和诊断包包含新程序记录。
9. 全程无网络请求、无 UAC、无自动拦截。
