# 4.0 VM 验收说明

> 4.0 = 反端口扫描 + 临时来源 IP 封禁。
> 只在验收用的 VMware 虚拟机里跑；开发机只编译 / 打包，不执行会改系统状态的测试。

## 1. 准备

1. 开发机打包：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\build\publish.ps1
   ```

   脚本会把官方 `npcap-1.90.exe` 和 `Npcap-LICENSE.txt` 放进
   `WinAppGuardSetup.exe` 的内置载荷，并校验 SHA-256。

2. 把整个 `默认项目` 文件夹复制到 VM，例如：

   ```text
   C:\Users\VM\Downloads\默认项目\
   ```

3. 在干净 VM（未装 Npcap）上管理员运行：

   ```powershell
   C:\Users\VM\Downloads\默认项目\dist\WinAppGuardSetup.exe
   ```

4. 安装器提示是否安装 Npcap 时选 `Y`，在官方 Npcap GUI 中保持：

   ```text
   [ ] Install Npcap in WinPcap API-compatible Mode
   [ ] Support loopback traffic
   [ ] Support raw 802.11 traffic
   [x] Restrict Npcap driver's access to Administrators only
   ```

   - 如果选 `n`：WinAppGuard 主功能正常，防护页显示 Npcap 未安装，反扫描不可用；
   - Npcap 安装失败/取消不应导致 WinAppGuard 安装失败；
   - 安装完成后不需要重启（除非 Npcap 返回 3010）。

## 2. 自动验收

管理员 PowerShell，**必须 cd 到 `dist-tools`**（脚本要和 `WinAppGuard.SelfCheck.exe` 在同一目录；
放错目录会直接报错退出，不会静默跳过步骤）：

```powershell
chcp 65001 > $null
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
cd C:\Users\VM\Downloads\默认项目\dist-tools

& .\4.0-验收脚本.ps1 -LogPath "$env:USERPROFILE\Desktop\wag-4.0-验收.txt"
"退出码 = $LASTEXITCODE"
```

- 不要用 `powershell -File ... | Tee-Object`：子进程输出会被父进程按 GBK 解码，中文全是乱码；
- `-LogPath` 由脚本内部 `Start-Transcript` 记录，控制台和文件都是完整输出；
- 不想重启服务可加 `-SkipServiceRestart`。

脚本顺序：

1. 版本 / Npcap / 服务检查；
2. 重启服务；
3. `--antiscan-test` 离线阈值 / 状态 / 协议；
4. `--wfp-inbound-test` 真实 WFP 入站过滤；
5. `--ids-test`、`--traffic-records-test` 回归；
6. `--etw-network-test`；
7. `--service-35-test`；
8. `--service-antiscan-test`（Npcap 状态 / 设置 / 解除 / 清空）；
9. `--service-ids-test`；
10. 临时锁网；
11. 清空流量；
12. ETW 会话；
13. 服务日志 `WAG-ANTISCAN-*`、`WAG-IDS-*`、`WAG-TRAFFIC-*`、`WAG-DNS-*`。

> `--service-antiscan-test` 会清空反扫描事件并解除临时封禁；
> `--service-traffic-clear-test` 会清空流量计数。都不修改规则 / 白名单 / 锁网。

## 3. 手工扫描测试

准备第二台 VM（Linux 或 Windows）对验收机做扫描：

```bash
# 连接扫描（开放/关闭端口都能看到 accept）
nmap -sT -p 1-1000 <VM_IP>

# SYN 扫描（需要 Npcap 或 Linux raw socket）
nmap -sS -p 1-1000 <VM_IP>
```

观察：

- 「防护」页出现来源 IP、端口数、SYN 数；
- 未开启自动封禁时：只有“仅告警”；
- 开启自动封禁后，高危扫描来源进入“临时封禁”列表；
- 解除选中 / 解除全部后，来源可以重新建立连接；
- 到期后封禁自动消失。

注意：

- 只支持 **入站 TCP SYN**；UDP 扫描、UDP Flood 不在 4.0 范围；
- 扫描源 IP 可能被 NAT/网关改写；封的是看到的来源 IP；
- 源 IP 可伪造，自动封禁可能被滥用，因此默认关闭。

## 4. 关键观察指标

| 指标 | 期望 |
|---|---|
| 空闲 CPU | < 1%（16 核） |
| 正常浏览 30 分钟 | 反扫描事件 0–少量；无高危误报 |
| 1k SYN/s | CPU 可接受（POC 目标 < 2–3%） |
| 内存 | 与 3.7 基线接近，增长平稳 |
| 事件丢失 | 服务日志无持续失败 |
| 临时封禁 | 到期释放、重启恢复、卸载清理 |

## 5. 升级 / 卸载

- 从 3.7 覆盖安装即可；规则、白名单、IDS 告警保留；
- 修复时不重复安装 Npcap；已安装则跳过；
- 卸载**不自动卸载 Npcap**（Wireshark/Nmap 可能共用），只删除 WinAppGuard；
- 反扫描临时封禁随服务卸载清理，不留下 WFP 过滤器。

## 6. 失败时收集

- `4.0-验收脚本.ps1` 完整输出和退出码；
- `C:\ProgramData\WinAppGuard\logs` 最近 800 行；
- `C:\ProgramData\WinAppGuard\antiscan\state.json`；
- `C:\Program Files\WinAppGuard\Npcap-LICENSE.txt`（确认随包许可文件存在）；
- `logman query -ets`；
- 「防护」页截图（状态行 + 事件 + 临时封禁）。
