# 5.12 VM 验收

> 只在 VM / 测试机执行。会安装/卸载服务、修改 WFP 规则。
> 本机正在使用的 WinAppGuard 不要用作验收环境。

## 1. 覆盖安装

准备：

- 5.10.1 完整 dist（含 `WinAppGuardSetup.exe` 和 `WinAppGuardSvc.exe`）
- 5.12.0 完整 dist

管理员 PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\build\upgrade-matrix.ps1 `
  -OldSetup "A:\backup\5.10.1\WinAppGuardSetup.exe" `
  -NewSetup ".\dist\WinAppGuardSetup.exe"
```

判据：

```text
旧版安装后：服务/界面 = 5.10.1
只运行一次新版 --install 后：服务/界面 = 5.12.0
管道 = WinAppGuard.Control.v4
doctor = service OK / protocol OK / payload-contract OK / installed-versions OK
```

失败时查看：

```text
%ProgramData%\WinAppGuard\logs\setup-*.log
%ProgramData%\WinAppGuard\logs\winappguard-*.log
```

## 2. IPC 并发

```powershell
dotnet run --project tools\SelfCheck\SelfCheck.csproj -c Release -- `
  --perf --perf-iterations 50 --perf-threads 10 --perf-requests 100
```

判据：

```text
S5 并发：errors=0
没有 TimeoutException
```

## 3. 性能基线

```powershell
dotnet run --project tools\SelfCheck\SelfCheck.csproj -c Release -- `
  --perf --perf-iterations 300 --perf-threads 10 --perf-requests 100 `
  --perf-out perf-5.12.json
```

把结果填入 `docs/perf-baseline-5.12.0.md`。

S6（2000 条导入）/S7（巡检并发）在 VM 上手动执行：

1. 导入 2000 条规则，记录总耗时和服务日志里的 `elapsed=...ms`；
2. 导入期间刷新规则页，确认不卡顿；
3. 外部删除 1/10/100 条规则，确认 10 秒内补回；
4. 导入 + 巡检并发，确认没有规则被误删。

## 4. 功能回归

- 规则页：新增/删除/编辑分组/导入导出/严格模式；
- 10 个检测页：刷新、告警已读、清空、设置保存；
- 流量页：暂停/继续/清空；
- 审计页：开关、保留天数、域名查询、清空；
- 普通权限写操作弹 UAC，提权助手回写结果；
- 停服务后界面离线只读，重启后自动恢复。
