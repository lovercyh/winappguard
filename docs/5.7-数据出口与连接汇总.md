# 5.7 数据出口与连接汇总

> 状态：已实现，待验收
> 日期：2026-11-08
> 范围：连接页按程序汇总、五个页面导出当前视图、诊断包。
> 明确不做：自动拦截、域名拦截、HTTPS 解密、自动更新、内核驱动、逐条规则启停。

## 1. 连接页按程序汇总

- 工具条新增「按程序汇总」开关，默认关闭。
- 明细模式保持原有 TCP 连接列表，完全不变。
- 汇总模式一行一个程序，显示：
  - 程序名 / 程序路径 / PID
  - 连接数 / 远端地址数 / 已建立 / 监听 / 其它状态
  - 上传 / 下载 / 总计
  - 阻止状态 / 白名单 / 数字签名
- 分组规则：
  - 有程序路径：按路径合并，同一程序多开实例进同一行；
  - 没有路径：按 PID 合并，汇总行不能执行阻止 / 白名单动作。
- 流量取代表连接上的程序级累计值，**不做组内求和**，否则会按连接数重复计算。
- 汇总行仍复用原动作逻辑：阻止、允许、加入白名单、复制路径、右键菜单。
- 汇总模式有自己的排序：程序名、连接数、远端数、上传、下载、总计。

## 2. 导出当前视图

支持页面：

| 页面 | 导出内容 |
|---|---|
| 联网连接 | 当前明细或汇总视图 |
| 记录 | 当前搜索 / 只看拦截筛选后的记录 |
| DNS | 当前搜索后的 DNS 记录 |
| 反网络攻击 | 当前告警列表 |
| 流量 | 当前搜索 / 排序后的按程序流量 |

格式：

- 默认 CSV，可选 JSON。
- CSV 使用当前界面语言的表头，UTF-8 BOM + CRLF；包含逗号、引号、换行的字段按 RFC 4180 转义，首尾空格也加引号。
- JSON 使用固定英文 key，包含 `format`、`version`、`exportedUtc`、`toolVersion`、`view`、`columns`、`rows`。
- 空视图不生成文件，给出明确提示。
- 导出的是**当前视图**，不是全量数据。
- 只写用户选择的本地文件，不联网、不提权、不上传。

CLI：

```text
WinAppGuard --connections [--limit N] [--json]
WinAppGuard --dns [--limit N] [--json]
```

两者都是只读命令，沿用 5.3 的 JSON 外壳和退出码。

- `--connections` 包含监听端点和无归属连接，隐藏本机回环；默认 `--limit 50`。
- `--dns` 读取服务当前保留的最近记录；默认 `--limit 50`。

## 3. 诊断包

设置页「数据与隐私」区域新增「生成诊断包…」。

生成前确认框明确列出：可能包含程序路径、远端 IP、DNS 查询、防火墙规则和审计记录；只应交给可信的人。

zip 内容（默认提供 CSV，原始 JSON 放在 `data/raw/`）：

```text
README.txt
summary.txt
system.txt
service-status.json
npcap.json
settings.json
data/connections.csv
data/dns.csv
data/rules.csv
data/audit.csv
data/traffic.csv
data/network-alerts.csv
data/network-blocks.csv
data/ids-alerts.csv
data/anti-scan.csv
data/anti-scan-blocks.csv
data/lan.csv
data/dns-security.csv
data/ipv6-security.csv
data/config-integrity.csv
data/name-resolution.csv
data/audit/*.jsonl
data/raw/connections.json
data/raw/rules-snapshot.json
data/raw/service/*.json
logs/ui/*
logs/service/*
```

说明：

- 默认 CSV 可直接用 Excel 打开；`data/raw/` 保留服务原始 JSON，完整结构或嵌套字段以那里为准。
- `summary.txt` 记录生成时间、版本、服务/WFP/Npcap 状态、各数据条数、读取失败项和隐私提示。
- 不包含：受保护模式私钥、Suricata 规则文件、HTTPS 正文、任何未列出的系统数据。
- 生成过程只读本机数据，不联网、不弹 UAC、不自动上传。
- 服务未运行或某些日志不可读时，不会中断生成，会在 `summary.txt` 里注明。

## 4. 验证

```text
dotnet build WinAppGuard.sln -c Debug    0 警告 0 错误
SelfCheck --ui-check                     通过
SelfCheck --ui-language-test             通过
SelfCheck --cli-test                     通过
SelfCheck --network-detect-test          通过
SelfCheck --connection-filter-test       通过（含汇总分组）
SelfCheck --export-test                  通过
SelfCheck --diagnostics-test             通过
```

手工重点：

1. 汇总模式下浏览器多连接合并为一行，连接数和流量正确。
2. 汇总行选中后阻止 / 允许 / 白名单 / 右键复制正常。
3. 五个页面导出筛选后的视图；CSV 用 Excel 打开中文不乱码。
4. 诊断包解压后包含连接、DNS、规则、审计和日志；不包含私钥。
5. 导出和诊断包生成期间不产生网络请求，不弹 UAC。
