# 3.1 第 4 步 VM 验收（Owner SID + 管道 ACL + 服务 DACL）

> 这一步把**服务入口**和**服务控制**都收紧到所有者：
> - 命名管道：只允许 `SYSTEM` + 所有者 SID；
> - 服务 DACL：`SYSTEM` + 所有者完全控制；`Administrators` 仅查询/启动/读；
> - 其他账户（含其他管理员）不能连接、不能直接 `sc stop`。
>
> 管理员仍可通过接管所有权绕过，这是明确保留的能力。

## 一次性复制（管理员 PowerShell）

```powershell
& {
    $ErrorActionPreference = 'Stop'
    cd C:\Users\VM\Downloads\默认项目\dist-tools

    $version = (Get-Item .\WinAppGuardSetup.exe).VersionInfo.ProductVersion
    Write-Host "版本 = $version"
    if ($version -notlike '3.1+*') { throw "版本不是 3.1+：$version" }

    .\WinAppGuardSetup.exe --repair
    if ($LASTEXITCODE -ne 0) { throw "Setup --repair 失败，退出码 $LASTEXITCODE" }
    Write-Host "[PASS] Setup --repair" -ForegroundColor Green

    .\WinAppGuard.SelfCheck.exe --service-auth-test --no-pause
    if ($LASTEXITCODE -ne 0) { throw "service-auth-test 失败，退出码 $LASTEXITCODE" }
    Write-Host "[PASS] service-auth-test" -ForegroundColor Green

    .\WinAppGuard.SelfCheck.exe --service-acl-test --no-pause
    if ($LASTEXITCODE -ne 0) { throw "service-acl-test 失败，退出码 $LASTEXITCODE" }
    Write-Host "[PASS] service-acl-test" -ForegroundColor Green

    .\WinAppGuard.SelfCheck.exe --service-ping-test --no-pause
    if ($LASTEXITCODE -ne 0) { throw "service-ping-test 失败，退出码 $LASTEXITCODE" }
    Write-Host "[PASS] service-ping-test" -ForegroundColor Green

    .\WinAppGuard.SelfCheck.exe --ui-check --no-pause
    if ($LASTEXITCODE -ne 0) { throw "ui-check 失败，退出码 $LASTEXITCODE" }
    Write-Host "[PASS] ui-check" -ForegroundColor Green

    Write-Host "全部自动化验收通过。" -ForegroundColor Green
}
```

## 1. 服务 DACL

```powershell
sc.exe sdshow WinAppGuardSvc
```

期望能看到：

```text
D:(A;;GA;;;SY)(A;;GA;;;S-1-5-21-...)(A;;0x20014;;;BA)
```

- `SY`：SYSTEM 完全控制；
- `GA` + 你的 SID：所有者完全控制；
- `0x20014` + `BA`：Administrators 只有查询/启动/READ_CONTROL；
- 没有 `IU`、`WD`、`BU` 的完全控制 ACE。

`--service-acl-test` 会自动核对这 6 项。

## 2. 所有者界面

普通权限打开界面：

- 状态正常；
- 查看规则/记录正常；
- 改规则仍弹一次 UAC，成功后生效。

## 3. 非所有者管理员（手工，可选但建议）

用第二个管理员账户 B（不是所有者）登录，在**管理员** PowerShell 里：

```powershell
sc.exe stop WinAppGuardSvc
sc.exe start WinAppGuardSvc
Get-Content "C:\ProgramData\WinAppGuard\protected-mode\config.json"
cd C:\Users\VM\Downloads\默认项目\dist-tools
.\WinAppGuard.SelfCheck.exe --service-ping-test --no-pause
```

期望：

- `stop`：**拒绝访问**（服务 DACL 不允许停止）；
- `start`：允许（Administrators 有启动权限）；
- 读密钥配置：**拒绝访问**；
- `--service-ping-test`：连不上管道，失败；
- 界面：能启动但显示离线（第 5 步才做专门的“不是所有者”提示）。

> B 仍然可以杀服务进程、替换二进制、直接改 WFP；这是文档写明的边界。

## 4. 所有者卸载

用所有者账户运行：

```powershell
.\WinAppGuardUninstall.exe --uninstall
Test-Path "C:\ProgramData\WinAppGuard\protected-mode"   # False
sc.exe query WinAppGuardSvc                             # 1060（不存在）
```

期望卸载返回 0，服务、密钥、目录都删除。

## 5. 审计日志

用所有者做一次写操作（加入/删除一条规则），然后：

```powershell
Get-ChildItem "C:\ProgramData\WinAppGuard\logs" -File |
    Select-String -Pattern 'IPC 写操作|签名无效'
```

期望写操作日志包含：

```text
IPC 写操作：PID …，SID S-1-5-…，路径 C:\...，命令 write.rules...
```

签名失败日志包含 PID/SID/路径，但**不包含私钥或 DPAPI blob**。

## 6. 失败时请贴给我

- `--repair` 完整输出；
- `sc.exe sdshow WinAppGuardSvc` 原文；
- `--service-acl-test` 的失败项；
- B 账户 `sc stop` / `--service-ping-test` 的输出。

## 这一步明确没做

- 界面三态提示（正常 / 不是所有者 / 密钥不可用）在第 5 步；
- CLI 仍直接走 WFP，尚未改签名 IPC（第 5 步）；
- 非所有者管理员无法通过 `--reset-owner` 直接接管（当前要求用所有者身份；
  管理员仍可手工接管所有权）。
