# 3.2 VM 验收（GUI 多语言）

> 3.2 只改 GUI 语言。协议、服务、CLI、安装器、日志都不变。
> 非中文系统默认 English；中文系统默认中文；切换后重启生效。

## 一次性复制（管理员 PowerShell）

```powershell
& {
    $ErrorActionPreference = 'Stop'
    cd C:\Users\VM\Downloads\默认项目\dist-tools

    $version = (Get-Item .\WinAppGuardSetup.exe).VersionInfo.ProductVersion
    Write-Host "版本 = $version"
    if ($version -notlike '3.2+*') { throw "版本不是 3.2+：$version" }

    .\WinAppGuardSetup.exe --repair
    if ($LASTEXITCODE -ne 0) { throw "Setup --repair 失败，退出码 $LASTEXITCODE" }

    .\WinAppGuard.SelfCheck.exe --ui-language-test --no-pause
    if ($LASTEXITCODE -ne 0) { throw "ui-language-test 失败，退出码 $LASTEXITCODE" }

    .\WinAppGuard.SelfCheck.exe --ui-language-dpi-test --no-pause
    if ($LASTEXITCODE -ne 0) { throw "ui-language-dpi-test 失败，退出码 $LASTEXITCODE" }

    .\WinAppGuard.SelfCheck.exe --ui-check --no-pause
    if ($LASTEXITCODE -ne 0) { throw "ui-check 失败，退出码 $LASTEXITCODE" }

    .\WinAppGuard.SelfCheck.exe --service-auth-test --no-pause
    if ($LASTEXITCODE -ne 0) { throw "service-auth-test 失败，退出码 $LASTEXITCODE" }

    .\WinAppGuard.SelfCheck.exe --service-acl-test --no-pause
    if ($LASTEXITCODE -ne 0) { throw "service-acl-test 失败，退出码 $LASTEXITCODE" }

    Write-Host "自动化验收通过。" -ForegroundColor Green
}
```

期望：

- `ui-language-test` **11/11**
- `ui-language-dpi-test` **13/13**
- `ui-check` **240/240**
- `service-auth-test` **9/9**
- `service-acl-test` **6/6**

## 手工：中文 → English

1. 打开界面；
2. 点状态栏右侧「语言：简体中文」；
3. 选 English；
4. 提示重启 → 选“是”；
5. 重启后检查：
   - 5 个页签、工具栏、设置页、记录页全英文；
   - 托盘菜单英文；
   - 规则/白名单页说明英文；
   - 点“阻止选中程序联网”，确认框标题/正文/详情字段/按钮英文（程序路径不翻译）；
   - 严格模式开启确认、清空黑名单、退出确认；
   - 记录页状态行、右键菜单；
   - 150% DPI 下按钮不重叠/不截断。

## 手工：English → 中文

同样从状态栏切回「跟随系统」或「简体中文」，重启后用中文检查一遍，不能出现布局回归。

## 手工：默认语言

- 中文 Windows 新安装 → 中文；
- 非中文 Windows 新安装 → English；
- 语言设置按 Windows 用户保存，不影响规则/服务/所有者。

## 手工：非所有者 / 离线

- 非所有者账户打开界面：应仍是英文（或中文，取决于该用户设置），但规则只读；
- 服务停止：语言切换仍然可用，不要求管理员。

## 明确没做

- 安装器、CLI、服务日志仍中文；
- 不做运行中即时切换，必须重启 GUI；
- 个别系统/服务返回的错误原文可能仍为中文；GUI 固定文案已英文。
