# 4.0 反端口扫描 + 临时 IP 封禁设计

> 状态：已批准并实现（2026-10-27）。
> 范围：入站 TCP 端口扫描检测 + 来源 IP 临时封禁。
> **不做**：DPI / 载荷检测 / HTTPS 解密 / UDP 扫描 / 自动永久封禁 / 自研内核驱动。

## 1. 定位

4.0 不是完整的“入侵防御系统”，而是第一版**主机侧反扫描 IPS**：

- 只检测**入站 TCP SYN**；
- 能发现端口扫描（垂直 / 水平）；
- 可以按设置临时封禁扫描来源 IP；
- 封禁只拦**新入站连接**，不切断已有连接；
- 不读载荷、不做 DPI、不修改 Windows 防火墙设置。

## 2. 采集：Npcap

### 2.1 为什么用 Npcap

WFP 用户态 API 看不到所有入站 SYN；ETW accept 只能看到已经完成握手的连接。
Npcap 在 NDIS 层抓包，能看到打关闭端口的 SYN，适合做反扫描。

### 2.2 安装包策略（A1）

- `WinAppGuardSetup.exe` 内置**官方未修改**的 `npcap-1.90.exe`；
- 安装时询问用户是否安装 Npcap；
- 用户选 Y 后启动官方 GUI，**不静默安装**（免费版不支持 `/S`）；
- 启动参数锁定推荐选项：

  ```text
  /winpcap_mode=disabled
  /loopback_support=disabled
  /dot11_support=disabled
  /admin_only=enforced
  ```

- 用户选 n：WinAppGuard 主功能继续安装，反扫描不可用；
- Npcap 安装失败/取消：不阻塞主功能；
- 卸载**不自动卸载 Npcap**（Wireshark/Nmap 可能共用）；
- 安装目录保留 `Npcap-LICENSE.txt`；
- 安装包校验 Npcap 官方签名和固定 SHA-256。

> Npcap 随包分发依据项目所有者与 Nmap Software 的书面沟通；须保留记录，且不修改安装包。

### 2.3 采集实现

`Core/Diagnostics/AntiScan/NpcapCapture.cs`：

- 动态加载 `%SystemRoot%\System32\Npcap\wpcap.dll`；
- `pcap_findalldevs` 枚举活动网卡（跳过 loopback）；
- `pcap_open_live`：`snaplen=128`、`promisc=0`；
- BPF：

  ```text
  tcp and (tcp[tcpflags] & tcp-syn) != 0 and (tcp[tcpflags] & tcp-ack) == 0
  ```

- 只解析 IPv4 / IPv6 + TCP 头，不读载荷；
- 解析器本身能跳过 802.1Q / QinQ 头，但 BPF 的 `tcp` 原语在部分链路层不会自动跳过 VLAN 标签：
  如果网卡在把包交给 Npcap 之前没有剥掉标签，带 VLAN 的 SYN 可能抓不到。VM 验收时要专门测
  一次 VLAN / Hyper-V 虚拟交换机场景；需要时把 BPF 改成 `(tcp) or (vlan and tcp …)` 的组合。
- 只保留**目的地址是本机**的 SYN；
- 多网卡/VPN 重复包按 `(源 IP, 源端口, 目的 IP, 目的端口, seq)` 2 秒去重；
- 每 30 秒刷新本机地址列表；
- 线程退出或驱动异常时设置 `LastError`，服务看门狗 30 秒后重试。

> ⚠️ `pcap_pkthdr` 里的 `timeval` 在 Windows 上是**两个 32 位 long**（LLP64）。
> 托管结构体里用 C# 的 `long` 会变成 24 字节，`caplen` 从错误偏移读出，随后
> `Marshal.Copy` 会越界读包缓冲。必须用 `int`/`uint`，并用自检断言
> `Marshal.SizeOf == 16` 兜底。

## 3. 检测规则

`Core/Diagnostics/AntiScan/AntiScanAnalyzer.cs` 按来源 IP 维护 60 秒滑动窗口。

### 3.1 标准敏感度

| 条件 | 级别 |
|---|---|
| 60 秒内 ≥ 20 个不同端口 | 中 |
| 60 秒内 ≥ 50 个不同端口 | 高 |
| 10 秒内 ≥ 20 个不同端口 | 高 |
| 60 秒内 ≥ 10 个不同本机地址 | 中 |
| 60 秒内 ≥ 30 个不同本机地址 | 高 |

### 3.2 保守敏感度

阈值约为标准 2 倍：40 / 100 / 40 / 20 / 60。

### 3.3 抑制与冷却

- 同一来源同级别 10 分钟内不重复告警；
- 升级为高危时允许突破冷却；
- 解除封禁后 `ResetSource` 清掉冷却，允许重新触发；
- 回环、组播、`0.0.0.0`、`::` 来源忽略；
- 用户允许名单永不自动封禁。

### 3.4 边界

- 只覆盖到达本机网络栈的 TCP SYN；
- 硬件/上游防火墙直接丢弃的包看不到；
- 慢速扫描（低于窗口阈值）本版可能漏报；
- 源 IP 可伪造，自动封禁可能被滥用，所以默认关闭。

## 4. 临时封禁

### 4.1 WFP 层

使用用户态 WFP 过滤器：

- `FWPM_LAYER_ALE_AUTH_RECV_ACCEPT_V4`
- `FWPM_LAYER_ALE_AUTH_RECV_ACCEPT_V6`

条件：`FWPM_CONDITION_IP_REMOTE_ADDRESS` = 扫描来源 IP。
效果：只拦**新入站连接**，已有连接不受影响。

不做 `INBOUND_TRANSPORT` 全包丢弃，避免误伤已有会话；以后如需“强力模式”再加。

### 4.2 生命周期

- 默认关闭自动封禁；用户显式开启；
- 只有高危扫描才自动封；
- TTL 5 / 10 / 30 / 60 分钟，默认 10；
- 自动封禁上限 32 个来源（实现上限由状态和 UI 控制）；
- 到期由服务 5 秒定时器清理；
- 服务停止时删除反扫描过滤器，状态文件保留未到期项；下次启动恢复；
- 服务重启后重新创建过滤器；
- 卸载时随子层一起清理。

### 4.3 安全措施

- 默认网关、DNS、回环不自动封（允许名单可配置）；
- 自动封禁默认关闭；
- 临时封禁可在「防护」页手动解除；
- 不提供“永久自动封禁”；
- 不阻断已有连接，避免把正常会话打断。

## 5. 状态、协议与界面

### 5.1 协议（仍为 v2）

| 命令 | 类型 | 说明 |
|---|---|---|
| `query.antiscan` | 读 | 状态 + 事件 + 临时封禁 + 设置 |
| `write.antiscan.configure` | 写 | 开关 / 敏感度 / 自动封禁 / TTL / 允许名单 |
| `write.antiscan.release` | 写 | 解除一个或全部临时封禁 |
| `write.antiscan.clear` | 写 | 清空事件并解除全部封禁 |

`status` 增加：

- `antiScanEnabled`
- `antiScanCollecting`
- `antiScanNpcapAvailable`
- `antiScanBlockedCount`

### 5.2 数据

- `%ProgramData%\WinAppGuard\antiscan\state.json`：设置、允许名单、未到期封禁；
- 事件只保存在内存（最多 1000 条），服务重启后清空；
- 服务日志：`WAG-ANTISCAN-001` ～ `WAG-ANTISCAN-017`。

### 5.3 界面

新增「防护」页：

- 状态行：Npcap 版本 / 采集 / 敏感度 / 自动封禁 / 事件数 / 临时封禁数；
- 扫描事件表：时间、来源 IP、端口数、主机数、SYN 数、窗口、级别、处置、封禁至；
- 临时封禁表：来源 IP、封禁至、原因、事件 id；
- 操作：刷新、解除选中、解除全部、清空、设置；
- Npcap 未安装时明确显示“反扫描不可用”，不假装工作；
- 中英文、100% / 150% DPI。

## 6. 隐私与安全

- 只解析 TCP/IP 头，不保存载荷、URL、HTTPS 内容；
- 不上传任何数据；
- 事件和封禁只在本机；
- 安装 Npcap 是用户显式选择，不静默安装；
- 不修改 Windows 防火墙设置；
- 不写内核驱动，不使用未签名驱动；
- 自动封禁默认关闭，避免被伪造源 IP 利用。

## 8. 风险

| 风险 | 处理 |
|---|---|
| Npcap 免费版许可证 | 官方书面许可；保留记录；不修改安装包 |
| 免费版无静默安装 | 官方 GUI + 锁定选项；不承诺无人值守 |
| 源 IP 伪造 | 默认只告警；自动封禁 opt-in；TTL + 上限 |
| NAT / 网关 | 默认不自动封网关；封的是看到的来源 IP |
| 性能 | BPF 只抓 SYN、snaplen 128；VM 实测后定阈值 |
| 慢扫描漏报 | 4.0 只做窗口阈值；慢扫描放后续版本 |
| VLAN 标签导致 BPF 漏抓 | 解析器已支持 VLAN；VM 实测 VLAN/Hyper-V 后再决定是否扩展 BPF 表达式 |
| EDR/AV | Npcap 比 WinDivert 成熟；安装失败必须降级 |
| 服务停止留下过滤器 | 停止时删除；状态文件保留并恢复 |
