# 6.0：进程上下文、画像与检测增强

> 版本：6.0.0  
> 协议：v4（新增可选字段，不新增必需命令）

## 1. Kernel-Process ETW

- 默认开启，只订阅 Process keyword；
- PID + 开始时间窗口归因，支持 PID 复用；
- 父子进程、svchost 服务实例、LOLBin 规则 ID；
- ETW 失败每 10 秒自动重建，健康度显示重试次数和下次重试时间；
- 失败自动回退轮询归因，不阻塞服务和规则。

## 2. 健康度页

- ETW 运行状态、进程表条数、事件数、解析失败、LOLBin 命中；
- 服务模块健康状态；
- DNS 绕过计数与最近目标。

## 3. 程序画像

- 按进程记录告警数、远端地址/端口、分类、服务实例、LOLBin；
- EWMA 告警/小时；
- 冷启动期（7 天）只积累，不触发新检测；
- 画像页只读展示，数据来自服务状态。

## 4. 置信度

- 反网络攻击告警增加置信度（0–100）；
- 置信度 = 严重度 + 规则分类 + 进程归因确定度；
- 列表支持全部 / ≥60 / ≥80 筛选。

## 5. 局域网设备

- 「局域网设备」页按 MAC 聚合 ARP/DHCP 事件；
- 可信任选中设备；
- 信任后该 MAC 的 ARP/DHCP 告警静默。

## 6. DNS 绕过（最小版）

- 出站 UDP/TCP 53 到非系统 DNS；
- 出站 TCP 853（DoT）；
- 只计数，不保存域名正文；
- DoH 443 暂不检测，避免误报。

## 7. Suricata 精选档

- 默认档位改为「精选」；
- 分类：恶意软件 / 漏洞利用 / DNS / TLS-JA3 / 挖矿 / Web 客户端；
- 排除钓鱼与「其他」；
- 仍保留标准档和全量档。

## 8. ThreatFox 威胁情报

### 8.1 本地 IOC 库

- 数据：构建期快照 `threatfox/full.csv`（2026-11-28，约 15.5 万条）；
- 匹配：`ip:port` 出站 IPv4、`domain` 及其一级父域、URL 主机名、文件哈希 API；
- 默认最低置信度 75%，可在 IDS 设置中调整为 50/75/90/100；
- 只告警、不阻断；同一进程 + 目标的命中 10 分钟内去重；
- 硬白名单覆盖 Windows 更新、证书吊销、主流 CDN 等基础设施；
- 健康度页显示条数、快照日期、命中次数和加载错误。

### 8.2 Suricata 规则
 
- 随包提供 `threatfox.rules`（80,412 条）；
- 三个规则档位都会自动附加，按档位过滤置信度：
  - 精选：仅 100%（35,843 条）
  - 标准：≥ 90%（42,273 条）
  - 全量：全部（80,412 条）
- 与 ET Open 规则合并后写入 `active.rules`；
- 规则拼接与 `-T` 校验在后台执行，保存设置不会等待；
- 切换档位会中止上一次校验，按新档位重新准备；
- 规则数超过 6 万时，配置校验超时从 60 秒提高到 180 秒，超过 10 万时 600 秒。

### 8.3 数据与授权

- 随包数据来自用户提供的 ThreatFox 快照，条款见 `threatfox/NOTICE.txt`；
- 不做运行时联网更新，也不内置共享 Auth-Key；
- 后续如需自动更新，应使用用户自己的 abuse.ch Auth-Key 或取得 Spamhaus 授权。

## 9. 暂缓

- IOC 在线自动更新与商业授权数据源；
- DoH（443）检测。

## 10. 验收重点

1. ETW 运行、强杀服务后自动恢复；
2. 快速 PID 复用不串进程；
3. 健康度、程序画像、局域网设备页可打开；
4. 健康度显示 IOC 条数与快照日期；
5. 访问 ThreatFox 中的 IP/域名后，IDS 页出现「威胁情报」告警；
6. 信任设备后同类告警静默；
7. DNS 53/853 绕过计数增加；
8. 精选档默认启用，规则数少于标准档，标准档少于全量档；
9. 置信度筛选生效；
10. 三个档位都包含 ThreatFox 规则，切换档位后可正常重启 Suricata。
