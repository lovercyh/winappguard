# 4.1 VM 验收说明

> 4.1 = 精确流量统计（Npcap）+ 实时速率/曲线 + Npcap 变为安装前置。
> 只在验收 VM 上跑；开发机只编译/打包。

## 1. 安装（必须先测这条）

**A. 干净快照（未装 Npcap）**

| 操作 | 期望 |
|---|---|
| 运行 `dist\WinAppGuardSetup.exe`，看到说明后输入 `n` | 退出码 **8**；服务/文件/快捷方式/注册表项都没创建 |
| 输入 `Y`，在官方 GUI 里点取消 | 退出码 **8**；同样零残留 |
| 让 Npcap 安装失败（例如临时改名/占位） | 退出码 **9**；WAG 未安装 |
| 正常安装 | Npcap 选项：不勾 WinPcap 兼容 / loopback / 802.11，勾选仅管理员；`%ProgramFiles%\WinAppGuard` 下有 `npcap-1.90.exe` 与 `Npcap-LICENSE.txt` |

**B. 已装 Npcap 的机器**

- 直接跳过 Npcap GUI，安装正常完成；
- 覆盖安装（3.x/4.0 → 4.1）走修复流程，规则/白名单/IDS 告警保留。

**C. 驱动异常**

- 停掉 Npcap 服务后再装：安装应**成功**（`exit 0`），但打印“警告：打不开网卡”；
- 界面流量页显示“采集未运行”，其它功能正常。

**D. 卸载**

- 卸载不需要 Npcap，能完整删除 WAG；**不会**卸载 Npcap。

## 2. 自动验收

管理员 PowerShell，**在 `dist-tools` 里**运行：

```powershell
chcp 65001 > $null
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
cd C:\Users\VM\Downloads\默认项目\dist-tools

& .\4.1-验收脚本.ps1 -LogPath "$env:USERPROFILE\Desktop\wag-4.1-验收.txt"
"退出码 = $LASTEXITCODE"
```

脚本覆盖：

1. 版本 4.1 / Npcap / 安装目录里的官方安装包；
2. 重启服务；
3. `--traffic-capture-test`（离线聚合）；
3.1 `--traffic-live-test`（真实抓包冒烟：打开网卡 / 看到包 / 归属到程序）；
4. `--antiscan-test`（4.0 回归）；
5. `--wfp-inbound-test`（真实入站过滤器）；
6. 界面回归（列宽 / 中英文 / 150% DPI）；
7. `--service-traffic-precise-test`（采集 / 暂停 / 曲线 / 清空）；
8. `--service-antiscan-test`；
9. `--service-35-test`（DNS 仍可捕获、**回环不计**）；
10. `--service-ids-test`；
11. 临时锁网（会短暂断网）；
12. 清空流量统计；
13. ETW 会话与 `WAG-TRAFFIC-*` 日志。

## 3. 手工精度测试

第二台 VM 或同机工具均可（不要用回环，回环按设计不计）：

```bash
# TCP 双向 100 MB
iperf3 -s            # 验收机
iperf3 -c <验收机IP> -t 20

# UDP 100 MB
iperf3 -c <验收机IP> -u -b 100M -t 20
```

对照「流量页」里对应程序的入站/出站总量：

- TCP 误差 ≤ 1%，UDP 误差 ≤ 2%；
- 1000 次 1 KB 短连接要全部计入（可用 PowerShell 循环发 HTTP 请求）；
- 3000 次 DNS 查询计入 UDP；
- 「丢包」应为 0；若 > 0，页面会标“数据可能不完整”。

## 4. 手工界面项

- 曲线：5 分钟、每秒一个点，入站/出站两条线；
- 表格：入站/出站/下行/上行/总计/最后活动；
- 选中某行，状态行显示该行 TCP/UDP 明细；
- 「暂停统计」→ 按钮变「继续统计」，曲线停止；继续后恢复；
- 「清空…」→ 程序列表与曲线同时归零；
- 状态栏：`Npcap：已连接（1.90）`；停服务变「服务离线」；卸掉 Npcap 变「点击安装」并可拉起官方 GUI。

## 5. 环境与稳定性

- Hyper-V / VPN / 双网卡：不重复计数（对比 `Get-NetAdapterStatistics` 量级）；
- IPv6：能统计并归属；
- 24 小时 soak：CPU / 内存 / 丢包 / 曲线；无崩溃、内存无持续增长；
- 3.4–4.0 回归：规则、白名单、IDS、锁网、记录页、DNS 页、防护页。

## 6. 失败时收集

- `wag-4.1-验收.txt` 全文与退出码；
- `C:\ProgramData\WinAppGuard\logs` 最近 1200 行；
- `C:\ProgramData\WinAppGuard\antiscan\state.json`；
- 流量页截图（状态行 + 曲线 + 表格）；
- 安装器拒绝/失败时的控制台输出与退出码。
