# 6.0 Beta：进程上下文、画像与检测增强

> 版本：6.0.0-beta  
> 协议：v4（新增可选字段，不新增必需命令）

## 1. Kernel-Process ETW

- 默认开启，只订阅 Process keyword；
- PID + 开始时间窗口归因，支持 PID 复用；
- 父子进程、svchost 服务实例、LOLBin 规则 ID；
- ETW 失败每 10 秒自动重建，健康度显示重试次数和下次重试时间；
- 失败自动回退轮询归因，不阻塞服务和规则。

## 2. 健康度页

- ETW 运行状态、进程表条数、事件数、解析失败、LOLBin 命中；
- 服务模块健康状态；
- DNS 绕过计数与最近目标。

## 3. 程序画像

- 按进程记录告警数、远端地址/端口、分类、服务实例、LOLBin；
- EWMA 告警/小时；
- 冷启动期（7 天）只积累，不触发新检测；
- 画像页只读展示，数据来自服务状态。

## 4. 置信度

- 反网络攻击告警增加置信度（0–100）；
- 置信度 = 严重度 + 规则分类 + 进程归因确定度；
- 列表支持全部 / ≥60 / ≥80 筛选。

## 5. 局域网设备

- 「局域网设备」页按 MAC 聚合 ARP/DHCP 事件；
- 可信任选中设备；
- 信任后该 MAC 的 ARP/DHCP 告警静默。

## 6. DNS 绕过（最小版）

- 出站 UDP/TCP 53 到非系统 DNS；
- 出站 TCP 853（DoT）；
- 只计数，不保存域名正文；
- DoH 443 暂不检测，避免误报。

## 7. Suricata 精选档

- 默认档位改为「精选」；
- 分类：恶意软件 / 漏洞利用 / DNS / TLS-JA3 / 挖矿 / Web 客户端；
- 排除钓鱼与「其他」；
- 仍保留标准档和全量档。

## 8. 暂缓

- IOC 本地库：缺少可随包分发的合法数据源，暂缓；
- 后续可做本地导入 + 手动刷新。

## 9. 验收重点

1. ETW 运行、强杀服务后自动恢复；
2. 快速 PID 复用不串进程；
3. 健康度、程序画像、局域网设备页可打开；
4. 信任设备后同类告警静默；
5. DNS 53/853 绕过计数增加；
6. 精选档默认启用，规则数少于全量档；
7. 置信度筛选生效。
