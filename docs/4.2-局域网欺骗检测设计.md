# 4.2 局域网欺骗检测（ARP / 虚假 DHCP）设计

> 状态：设计待批准（2026-10-29）。
> 范围：ARP 欺骗检测（以本机为中心）+ 虚假 DHCP 检测 + 防护页三子标签 + 事件落盘。
> 不做：混杂模式、全网 ARP 监控、静态 ARP 写入、IPv6 RA guard、抓包落盘。

## 1. 目标与边界

- **能发现**：网关 MAC 被篡改、同一 MAC 声称多个 IP、同一 IP 频繁换 MAC、
  ARP 应答 sender MAC 与帧源不符；基线外的 DHCP 服务器、多 DHCP 服务器、
  OFFER 的网关/DNS 与基线不同、租期异常短。
- **不能发现**：其他主机之间的 ARP 欺骗（没有混杂模式/镜像端口）；
  交换机隔离的 Wi-Fi 客户端互不可见；VPN 隧道内通常没有 ARP/DHCP。
- **处置**：默认只告警。ARP 不做任何自动修复（WFP 管不到 L2）。
  DHCP 可选的“临时阻断该服务器”默认关闭，且以 POC 结果为准。

## 2. 已定决策

| # | 决策 |
|---|---|
| D1 | ARP 只覆盖影响本机的情况，文档与界面都写明 |
| D2 | 入口合并：防护页内嵌子标签「端口扫描 / 局域网 / IDS」 |
| D3 | DHCP 临时阻断为可选项，默认关闭、需二次确认、TTL 10 分钟 |
| D4 | 首次运行静默学习基线（10 分钟或直到网关/DHCP 出现），不弹窗 |
| D5 | 网卡用**排除名单**：排除已知虚拟网卡，**VPN 保留** |
| D6 | 基线与事件都落盘；事件保留期可选 **7 / 15 / 30 天，默认 7 天** |
| D7 | 默认只告警；可“信任当前网关 / 信任此 DHCP 服务器” |
| D8 | 只落事件元数据，不落报文、不做抓包导出 |

## 3. 采集

新增第三个独立 Npcap 会话（不与 4.0/4.1 的会话合并，记为技术债）：

```
BPF: arp or (udp and (port 67 or 68))
snaplen: 600（DHCP options）
promiscuous: 关
```

- 为什么单独开会话：ARP 不在 `tcp or udp` 内；DHCP options 需要 600 字节，
  抬高现有流量会话的 snaplen 会让每个包多拷 400 字节。
- ARP/DHCP 速率极低，额外句柄的代价可忽略。

### 3.1 网卡筛选（排除名单）

- **纳入**：以太网、Wi-Fi、VPN（TAP / WireGuard / OpenVPN / AnyConnect / PPP / SSTP / IKEv2 等）；
- **排除**（描述或名称包含，忽略大小写）：
  `Hyper-V`、`vEthernet`、`VMware`、`VirtualBox`、`WSL`、`Docker`、
  `Loopback`、`Npcap Loopback`、`Bluetooth`；
- 页面显示“当前纳入检测的网卡”，便于排查为什么某块网卡没有被检测；
- 该规则只作用于 4.2 的局域网会话，**不影响**流量/反扫描采集。

## 4. 检测规则

### 4.1 ARP

| 规则 | 级别 | 触发条件 | 误报来源 |
|---|---|---|---|
| `arp_gateway_mac_changed` | 高 | 网关 IP 的 MAC 与基线不同 | 换路由器、VRRP/HSRP 切换 |
| `arp_gateway_cache_mismatch` | 高 | 本机 ARP 缓存中的网关 MAC 与观测基线不同 | 同上 |
| `arp_mac_claims_many_ips` | 中 | 同一 MAC 10 分钟内声称 ≥3 个 IP | 代理 ARP、负载均衡 |
| `arp_ip_mac_flapping` | 中 | 同一 IP 60 秒内换 MAC ≥2 次 | 虚拟机迁移、网卡切换 |
| `arp_sender_mismatch` | 中 | ARP 应答 sender MAC ≠ 以太网源 MAC | 极少 |
| `arp_gratuitous_burst` | 低 | 同源免费 ARP >20 个/10 秒 | 路由器重启 |

### 4.2 DHCP

| 规则 | 级别 | 触发条件 | 误报来源 |
|---|---|---|---|
| `dhcp_unexpected_server` | 高 | 出现基线外的 server identifier | 合法第二台 DHCP |
| `dhcp_multiple_servers` | 高 | 同一网段同时出现 ≥2 个服务器 | DHCP 故障转移 |
| `dhcp_option_mismatch` | 中高 | OFFER 的网关/DNS 与基线不同 | 网络改造 |
| `dhcp_short_lease` | 中 | 租期 <60 秒 | 公共 Wi-Fi |
| `dhcp_server_not_gateway` | 中 | 服务器 MAC ≠ 网关 MAC | 三层交换机做 DHCP |

### 4.3 冷却与信任

- 同一（规则 + 关键值）**10 分钟**内不重复；
- 「信任当前网关 MAC / 信任此 DHCP 服务器」把当前值写入基线，并清掉冷却；
- 基线学习期（10 分钟或首次出现网关/DHCP）内只记 info，不告警。

## 5. 落盘

| 文件 | 内容 | 生命周期 |
|---|---|---|
| `%ProgramData%\WinAppGuard\lan\state.json` | 网关基线、DHCP 服务器、信任、设置、未到期阻断 | 永久（可重置） |
| `lan\events-YYYYMMDD.jsonl` | 事件元数据 | 按保留期（7/15/30 天，默认 7） |
| `lan\settings.json`（或并入 state） | `RetentionDays`、`DhcpBlockEnabled` | 永久 |

事件行示例：

```json
{"time":"2026-10-29T10:12:33Z","kind":"arp_gateway_mac_changed","severity":"high",
 "adapter":"以太网","gateway":"192.168.1.1","oldMac":"aa:bb:cc:00:11:22",
 "newMac":"de:ad:be:ef:00:01","detail":"网关 MAC 与基线不一致"}
```

- 权限沿用 `ServiceDataPermissions`（SYSTEM 写、管理员读、普通用户不可读）；
- 清理：服务启动时 + 每日一次，按文件名日期删除过期文件；
- 体积：正常每天 0～几十条，< 50 KB/天；
- 「清空」= 清内存 + 删除事件文件 + 解除全部 DHCP 阻断；不动基线（另有“重置基线”）。

## 6. DHCP 临时阻断（POC 门槛）

- 目标过滤器：`ALE_AUTH_RECV_ACCEPT_V4/V6` + UDP + 远端 IP = 服务器 IP + 本地端口 68；
- TTL 10 分钟，到期自动删除；服务停止时清理；
- 全局开关 `DhcpBlockEnabled` 默认 **false**；单个服务器需在页面二次确认；
- **POC 内容**：广播 DHCP 应答在 WFP 层能否按远端 IP 命中并被丢弃；
  若不能，**不做该功能**，只保留告警（会在 POC 结果里明确记录）。

## 7. 协议与数据

新增命令：

| 命令 | 类型 | 说明 |
|---|---|---|
| `query.lan` | 读 | 状态 + 事件 + 网关 + DHCP 服务器 + 阻断 |
| `write.lan.configure` | 写 | 保留期（7/15/30）、DHCP 阻断总开关 |
| `write.lan.clear` | 写 | 清空事件、解除阻断（不动基线） |
| `write.lan.trust` | 写 | 信任网关 MAC / DHCP 服务器 |
| `write.lan.block` | 写 | 临时阻断 / 解除某个 DHCP 服务器（仅 POC 通过） |
| `write.lan.reset-baseline` | 写 | 清空基线，重新学习 |

DTO：

- `LanStatusDto`：`Collecting`、`Adapters[]`、`BaselineReady`、`BaselineUtc`、
  `GatewayCount`、`DhcpServerCount`、`EventCount`、`BlockedCount`、`LastError`、`NpcapVersion`；
- `LanEventDto`：`Id`、`TimeUtc`、`Kind`、`Severity`、`Adapter`、`Detail`、
  `SourceMac?`、`TargetIp?`、`TargetMac?`、`Blocked`；
- `LanGatewayDto`：`Adapter`、`Ip`、`Mac`、`LearnedUtc`、`Trusted`；
- `LanDhcpServerDto`：`ServerIp`、`Mac`、`Adapter`、`Gateway`、`Dns`、`LeaseSeconds`、
  `FirstSeenUtc`、`Trusted`；
- `LanBlockDto`：`ServerIp`、`UntilUtc`、`Reason`、`EventId?`；
- `LanSettingsDto`：`RetentionDays`、`DhcpBlockEnabled`。

`ServiceStatus` 追加：`LanCollecting`、`LanEventCount`、`LanBlockedCount`、`LanBaselineReady`。

## 8. 界面

防护页改为内嵌子标签：

```
[防护]
  ├─ 端口扫描   4.0 现有内容，原样搬迁
  ├─ 局域网     新增
  └─ IDS        3.7 现有内容，只换容器，逻辑不动
```

「局域网」子页：

- 状态行：采集状态、Npcap 版本、纳入的网卡、基线时间、事件/阻断数量；
- 网关表：网卡 / 网关 IP / MAC / 学习时间 / 是否信任 + 「信任当前」；
- DHCP 服务器表：服务器 IP / MAC / 网卡 / 网关 / DNS / 租期 / 首次发现 + 「信任」；
- 事件表：时间 / 类型 / 级别 / 网卡 / 详情 / 是否阻断；
- 工具条：刷新、清空…、重置基线…、保存保留期（7/15/30）、「每 3 秒自动刷新」（默认开）；
- DHCP 阻断开关（默认关）+「临时阻断此服务器（10 分钟）」按钮（POC 通过才出现）；
- 托盘通知点击后定位到「局域网」；IDS 通知定位到「IDS」；扫描通知定位到「端口扫描」。

## 9. 测试

### 离线

- `--lan-test`：合成 ARP/DHCP 帧（构造字节），覆盖方向解析、DHCP options、
  各规则阈值、冷却、信任、保留期删除、DTO 往返；
- `--traffic-records-test` 等 UI 测试增加子标签布局、深链、DPI、中英文断言。

### VM

- 第二台 Linux VM：`arpspoof -i eth0 -t <victim> <gateway>` → 5 秒内高危；
- rogue DHCP（dnsmasq / yersinia）→ “基线外服务器”；再起第二个 → “多服务器”；
- OFFER 的网关/DNS 篡改、租期 30 秒 → 分别命中；
- Hyper-V / WSL / VPN 网卡识别：虚拟排除、VPN 保留；
- DHCP 阻断（若 POC 通过）：rogue 不再生效，10 分钟自动解除；
- 24 小时正常使用误报 0；重启后基线/事件保留；7/15/30 天清理生效。

## 10. 风险

| 风险 | 对策 |
|---|---|
| 只能看本机相关 ARP | 文档/界面写清；不承诺全网监控 |
| 换路由器/VRRP 误报 | 静默学习 + 信任 + 冷却 |
| 虚拟网卡 DHCP 风暴 | 排除名单 + 页面显示纳入网卡 |
| VPN 误判 | 用排除名单而非白名单 |
| 阻断 DHCP 打断续租 | 默认关、二次确认、10 分钟 TTL、一键解除 |
| WFP 拦不住广播 | POC 先行，不成立就砍掉阻断 |
| 第三会话开销 | 低频；记为技术债 |
| 合并页面回归 | 只搬容器不改逻辑；自检覆盖 |

## 11. 验收标准

1. ARP 伪造 5 秒内出高危，详情含旧/新 MAC；
2. 信任后不再告警，重启仍生效；
3. rogue DHCP → 高危；双服务器 → 高危；option 差异/短租期分别命中；
4. 24h 正常使用误报 0；
5. 阻断（若保留）：rogue 失效，10 分钟自动解除；
6. 事件重启后可见；7/15/30 天清理正确；清空生效；
7. 三子标签 + 深链 + 中英文 + 150% DPI 正常；IDS 行为与 4.1 一致；
8. 3.4–4.1 回归全通过；0 警告 0 错误。
