# 5.14：反网络攻击告警显示规则分类

> 版本：5.14.0  
> 协议：v4，无新增命令；`NetworkAlertDto` 增加 `RuleCategory` 字段

## 1. 问题

反网络攻击页的告警列表只显示规则名，看不出这条规则属于哪个分类。  
设置里已经有 8 个分类（恶意软件 / 漏洞利用 / DNS / TLS / JA3 / 挖矿 / 钓鱼 / Web 客户端 / 其他），但列表没有用上。

## 2. 为什么不能直接用 `Category`

EVE 告警里的 `alert.category` 是 Suricata 自己的粗分类，例如：

```text
A Network Trojan was detected
Attempted Administrator Privilege Gain
Web Application Attack
```

它和设置里的 8 个分类不是同一套体系，不能直接显示。

## 3. 实现

### 3.1 SID → 分类索引

标准档规则按分类拆在安装目录：

```text
rules\standard\malware.rules
rules\standard\exploit.rules
rules\standard\dns.rules
rules\standard\ja3.rules
rules\standard\coinminer.rules
rules\standard\phishing.rules
rules\standard\web_client.rules
rules\standard\other.rules
```

每条规则都有唯一 `sid`，所以启动后解析这些文件，建立：

```text
SID → malware / exploit / dns / ja3 / coinminer / phishing / web_client / other
```

- 只构建一次，约 1.4 万条，首次解析约 100–200 ms；
- 服务启动时后台预热；
- 文件缺失或读取失败时静默降级，不影响检测；
- 注释行、`content` / `pcre` 里的 "sid:" 文本不会被误判。

实现：`src/WinAppGuard.Core/Diagnostics/NetworkDetection/NetworkRuleCategoryIndex.cs`

### 3.2 数据流

```text
EveAlertReader → NetworkAlert（SID）
→ NetworkDetectionHost.Query 时按 SID 解析分类
→ NetworkAlertDto.RuleCategory
→ 界面 / 导出 / 通知 / CLI
```

分类不写入告警存储：

- 历史告警也能按 SID 得到分类，不需要迁移；
- 规则文件更新后重启服务即可生效；
- 告警记录本身保持原样。

### 3.3 界面

告警列表新增「分类」列：

```text
时间 | 级别 | 分类 | 状态 | 规则 | 远端 | 进程 | 证据 | 拦截状态
```

列表上方新增分类筛选：

```text
全部分类 / 恶意软件 / 漏洞利用 / DNS / TLS / JA3 /
挖矿 / 钓鱼 / Web 客户端 / 其他 / 未分类
```

筛选只作用于当前列表，不改变告警数据和检测行为。

### 3.4 其它出口

- 导出 CSV / HTML 增加「分类」列；
- 托盘高危告警标题前显示 `[分类]`；
- `wag network alerts` 文本输出增加分类列，`--json` 自动包含新字段；
- 分类列悬停显示 Suricata 原始分类。

## 4. 限制

- 标准档：分类准确；
- 全量档：额外规则不在标准分类文件里，显示「未分类」，悬停仍能看到原始分类；
- 分类只读取本机规则文件，不联网、不写系统、不碰 WFP。

## 5. 测试

- `NetworkRuleCategoryIndexTests`：
  - SID 提取；
  - 注释 / 空行 / `content` 里的 "sid:" 不误判；
  - 重复 SID 保留第一次分类。
- `ResponseSemanticsTests`：`RuleCategory` JSON 往返。
- 界面：`--render-docs` 重新生成 `15-anti-network-attack.png`。

## 6. VM 验收

```text
1. 打开「反网络攻击」页；
2. 确认列表出现「分类」列，历史告警也有分类；
3. 用分类筛选切到「恶意软件」「漏洞利用」「未分类」；
4. 导出 CSV，确认有「分类」列；
5. 触发一条高危告警，确认托盘通知带 [分类]；
6. 切到全量档，确认标准规则仍有分类、额外规则显示「未分类」。
```
