# 5.13 VM 验收

> 只在 VM 测试。5.13 会写入 WFP 规则，但不会安装/卸载服务。

## 1. 黑名单文件夹

准备一个测试目录：

```text
C:\WagTest\Black\
  a.exe
  b.exe
  sub\c.exe
  note.txt
```

操作：

```text
黑名单 → 添加文件夹… → 选择 C:\WagTest\Black
→ 勾选“包含子文件夹”
→ 扫描
→ 确认列表里有 a.exe / b.exe / sub\c.exe，没有 note.txt
→ 添加选中
```

判据：

- 规则页出现 3 条阻止规则；
- 分组为 `文件夹黑名单：Black`；
- a/b/c 联网被阻止；
- note.txt 不在列表；
- 再次扫描同一文件夹时，3 条都显示“已存在”。

## 2. 白名单文件夹（严格模式）

准备：

```text
C:\WagTest\White\
  allowed.exe
```

操作：

```text
开启严格模式
→ 白名单 → 添加文件夹… → 选择 C:\WagTest\White
→ 扫描 → 勾选“我理解风险”
→ 添加选中
```

判据：

- 白名单出现 allowed.exe；
- 严格模式下 allowed.exe 能联网；
- 未加入白名单的程序仍被阻止；
- 不勾选风险确认时“添加选中”不可用。

## 3. 边界

- 含 2000+ exe 的目录：只显示前 2000，并提示上限；
- 不存在的目录：扫描报错；
- UNC 路径：提示不支持；
- 只有 `.bat`/`.txt`：提示没有 `.exe`；
- 受保护程序（如 System32 下的关键进程）：显示“受保护，跳过”；
- 取消扫描：不添加任何规则。

## 4. 5.13 修复验证

- 直接使用原有“导入…”功能导入 block/allow 文件，确认仍然成功；
- 检查服务日志 `WAG-RULE-031` 中有 `engineOpens=1` 和耗时。
